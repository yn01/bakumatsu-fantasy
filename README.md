# 幕末ファンタジーRPG

幕末を舞台としたWebブラウザRPGゲーム。主人公・坂本龍馬の生い立ちから脱藩までを描く。

> **📢 本リポジトリはデモ版です**
>
> 現在公開されているのは「土佐編（幼少期〜脱藩）」の**デモ版**です。
> - **プレイ時間**: 30分〜1時間
> - **完全版開発計画**: [`docs/PLAN.md`](docs/PLAN.md) の「Phase 7-12: 完全版開発計画」を参照

## 🎮 デモ版の内容

### プレイアブルコンテンツ
- **ストーリー**: 序章 + 3章 + エピローグ（計31 KB）
  - 序章: 才谷屋での幼少期、身分制度の描写
  - 第1章: 江戸小栗流への入門、剣術修行
  - 第2章: 武市半平太との出会い、土佐勤王党
  - 第3章: 藩の守旧派との対立、脱藩の決意
  - エピローグ: 土佐を離れ、新たな道へ

### ゲームシステム
- **フィールド探索**: マップ移動、NPC会話、トランジション
- **バトルシステム**: ターン制コマンドバトル（FF1-3スタイル）
- **成長システム**: レベルアップ、スキルツリー、経験値獲得
- **装備システム**: 武器・防具の装備、ステータス強化
- **イベント**: 16種類のコマンド、選択肢分岐、フラグ管理
- **セーブ/ロード**: 3つのセーブスロット、タイトル画面・メニューから操作可能
- **サウンド**: BGM/SE再生（Howler.js）※音声ファイルは未実装

### プレイアブルキャラクター
- **坂本龍馬**: 剣士クラス、初期レベル1
- **武市半平太**: 軍師クラス（ストーリーで加入）

### 敵
- **訓練相手**: 剣術修行用（序盤）
- **守旧派の刺客/侍**: 土佐藩保守派（終盤）

## 🚀 セットアップ

```bash
# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```
