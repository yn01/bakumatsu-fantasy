#### バグ修正詳細（2026-02-14）

**Issue #1: 才谷屋マップの衝突判定**
- **問題**: 2階から1階への通路が通行不可になっていた
- **原因**: collision配列のy=11,16の通路タイルが衝突判定（1）になっていた
- **修正**: `saigaitaya.json` - y=11,16の通路タイル（x=13-16）を通行可能（0）に変更
- **コミット**: `4ff3235` - "Fix collision detection and implement camera follow system"

**Issue #2: マップロード時のAbortError**
- **問題**: React Strict Modeでマップロード時にAbortErrorがコンソールに出力される
- **原因**: useEffectの2回実行によるAbortControllerのキャンセルを全てエラーログに出力
- **修正**: `MapRenderer.ts` - AbortErrorの場合はconsole.errorを出さないように変更
- **コミット**: `4ff3235`

**Issue #3: カメラ追従システム未実装**
- **問題**: キャラクターが画面外に移動すると見えなくなる
- **原因**: カメラ位置が固定（0, 0）だった
- **修正**: `Field.tsx` - キャラクター中心にカメラを配置、マップ境界内にクランプ
- **コミット**: `4ff3235`

**Issue #4: マップ遷移後のキーボードロック**
- **問題**: kochi_townマップに遷移後、キーボード入力が無効化される
- **原因**: mapId変更によるuseEffect再実行でゲームループが再起動され、transitionSystem.isTransitioning()がtrueのままになる
- **修正**: `Field.tsx` - progressStore更新をフェードイン完了後に移動、デバッグログ追加
- **コミット**: `f1b7ef4` - "Fix map transition keyboard lock issue"

**修正ファイル**:
- `public/data/maps/saigaitaya.json` (Issue #1)
- `src/systems/field/MapRenderer.ts` (Issue #2)
- `src/components/game/Field.tsx` (Issue #3, #4)
