## プロジェクト概要

幕末を舞台としたWebブラウザRPGゲーム。主人公・坂本龍馬が、その生い立ちから幕末の激動を駆け抜ける物語をロールプレイする。ストーリーは司馬遼太郎「龍馬がゆく」をベースに史実に基づいて構成。

## デモ版スコープ

- **範囲**: 土佐編（幼少期〜脱藩）
- **プレイ時間**: 30分〜1時間
- **目的**: システム検証とフィードバック収集

## 機能要件

### 1. ゲームシステム

#### 1.1 バトルシステム
- **形式**: ターン制コマンドバトル（FF1-3スタイル）
- **コマンド**: 攻撃 / 技 / 防御 / アイテム
- **エンカウント**: ランダムエンカウント（フィールド歩行時）

#### 1.2 マップ・移動
- **視点**: トップダウン2D（見下ろし視点）
- **操作**: キーボード（矢印キー移動、Enter/Space決定、Escキャンセル）、ゲームパッド、マウス/タッチ
- **デモ版マップ**:
  - 龍馬の生家（才谷屋）
  - 高知城下町
  - 山内容堂道場
  - 浦戸湊

#### 1.3 成長システム
- **レベルアップ**: 経験値蓄積でレベルアップ、ステータス自動上昇
- **スキルツリー**: レベルアップ時にポイント取得、スキル習得
- **スキルテーマ**: 剣術流派（北辰一刀流の技など）
  - 例: 「一の太刀」「龍の剣」「切り払い」

#### 1.4 装備・アイテム
- **装備スロット**: 武器 + 防具（2スロット）
- **消費アイテム**: 回復薬、解毒剤など基本的なもの
- **通貨**: 両（りょう）

#### 1.5 施設

**デモ版実装範囲**:
- **ショップ**: 武器・防具・アイテム購入
- **宿屋**: HP/状態回復
- **道場**: スキル習得・強化
- **闘技場**: 任意バトルで経験値稼ぎ

**将来拡張用**（デモ版範囲外）:
- **造具屋**: 装備強化システム

#### 1.6 パーティシステム
- **編成**: 固定パーティ（ストーリー進行で自動加入/離脱）
- **最大人数**: 4人
- **デモ版メンバー**: 坂本龍馬、武市半平太

### 2. キャラクター

#### 2.1 プレイアブルキャラクター（デモ版）
| キャラ | 役割 | 特徴 |
|--------|------|------|
| 坂本龍馬 | 主人公・剣士 | バランス型、成長ポテンシャル高 |
| 武市半平太 | 仲間・剣士 | 攻撃特化、土佐勤王党の同志 |

#### 2.2 敵キャラクター（デモ版）
| 勢力 | 説明 | 出現場所 |
|------|------|----------|
| 上士・役人 | 郷士を差別する支配層 | 城下町、街道 |
| 藩の守旧派 | 改革を拒む保守派藩士 | 道場、城下 |
| 山賊・浪人 | 街道の野盗 | 街道、山中 |

### 3. ストーリー（デモ版）

**土佐編 - 龍の目覚め**

1. **プロローグ**: 才谷屋での幼少期、身分制度の理不尽を知る
2. **第一章**: 江戸小栗流への入門、剣術修行の始まり
3. **第二章**: 武市半平太との出会い、土佐勤王党への接近
4. **第三章**: 藩の守旧派との対立、脱藩の決意
5. **エピローグ**: 土佐を離れ、新たな道へ

### 4. UI/UX

#### 4.1 画面構成
- **フィールド画面**: マップ表示、キャラクター移動
- **バトル画面**: 敵表示、コマンド選択、ステータス表示
- **メニュー画面**: アイテム、装備、スキル、ステータス、セーブ
- **会話画面**: メッセージボックス（画面下部）

#### 4.2 チュートリアル
- ストーリー組み込み形式（序盤イベントで自然に学習）

### 5. グラフィック

- **スタイル**: 32×32ピクセル（SFC風ドット絵）
- **キャラクター**: 歩行アニメーション（4方向×3フレーム）
- **バトル**: サイドビュー（味方左、敵右）
- **マップチップ**: 和風テーマ（瓦屋根、畳、障子など）

### 6. サウンド

- **フィールドBGM**: 各マップごとに専用曲
- **バトルBGM**: 通常戦闘、ボス戦闘
- **SE**: 決定音、キャンセル音、攻撃音、回復音、レベルアップ音など
- **素材**: フリー素材またはAI生成音源を使用

### 7. データ管理

#### 7.1 セーブシステム
- **保存先**: ブラウザLocalStorage
- **セーブスロット**: 3枠 + 自動セーブ1枠
- **自動セーブ**: マップ切替時に自動実行

**保存対象データ**:
- プレイ状況（プレイ時間、現在の章）
- マップ位置（現在のマップ、座標）
- パーティ状態（メンバー、編成）
- キャラクター状態（レベル、経験値、HP/MP、習得スキル、装備）
- 所持品（アイテム、装備、所持金）
- 進行フラグ（イベント完了状態、訪問済みマップ）
- ゲーム設定（音量、メッセージ速度）

**データ整合性**:
- バージョン管理による互換性維持
- データ破損検知メカニズム
- ロード失敗時のフォールバック処理

詳細仕様は `docs/PLAN.md` のセクション5.6、6.3を参照。

#### 7.2 ゲームデータ
- **形式**: JSONファイル（キャラ、敵、アイテム、スキル、マップ、イベント）
- **配置**: `public/data/` 配下
- **ロード**: 起動時およびマップ切替時に動的ロード

## 実装フェーズ

### Phase 1: 基盤構築
- プロジェクト初期化（Vite + React + TypeScript）
- 基本ディレクトリ構造
- 状態管理セットアップ
- キーボード入力システム

### Phase 2: フィールドシステム
- マップレンダリング
- キャラクター移動
- マップ切り替え
- NPC配置と会話

### Phase 3: バトルシステム
- ターン制バトル基盤
- コマンド選択UI
- ダメージ計算
- 勝敗判定

### Phase 4: 成長・装備システム
- レベルアップ処理
- スキルツリー
- 装備変更
- ショップ・施設

### Phase 5: イベント・ストーリー
- イベントスクリプト実行
- 会話システム
- ストーリーフラグ管理
- デモ版シナリオ実装

### Phase 6: サウンド・仕上げ
- BGM/SE実装
- タイトル画面
- セーブ/ロード
- バランス調整

### Phase 7: デモ版マップ＆シナリオ統合
- マップデータ作成（才谷屋、高知城下町、山内容堂道場、浦戸湊）
- シナリオ統合（ScenarioManager、チャプター管理）
- 敵データ追加（8種類）
- デバッグ機能（DebugPanel）

### Phase 8: ストーリー拡張（完全版シナリオ）
- 新キャラクター5人（勝海舟、西郷隆盛、木戸孝允、中岡慎太郎、お龍）
- 新マップ3つ（神戸港、京都、近江屋）
- 新シナリオ5章（第4章〜最終章）
- エンディング2分岐

### Phase 9: ゲームシステム拡張
- サイドクエスト20個
- 隠しダンジョン（ボス5体、究極装備6種）
- 実績システム（30種類）、図鑑システム（3種）、New Game+
- 難易度選択（Easy/Normal/Hard/Very Hard）
- ショップNPC統合（10店舗）

### Phase 10: 入力・ビジュアル・設定強化
- ゲームパッド入力対応（InputManager、GamepadInputProvider）
- マウス/タッチ入力対応（MouseTouchInputProvider）
- プロシージャルスプライト生成（SpriteGenerator、TilesetGenerator、BattleBackgroundGenerator）
- アニメーションシステム（AnimationManager、BattleEffects）
- 設定画面（SettingsScreen）

## 検証方法

1. **ユニットテスト**: Vitest でバトル計算、状態管理をテスト
2. **E2Eテスト**: Playwright でゲームフロー確認
3. **手動テスト**: デモ版通しプレイでバランス確認
4. **ブラウザ確認**: Chrome, Firefox, Safari での動作確認
